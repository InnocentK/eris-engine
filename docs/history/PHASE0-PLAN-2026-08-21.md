## A. Points of agreement (all four planners)
- Pydantic v2 records, `extra="forbid"`, `origin` on every record, one
  `SCHEMA_VERSION`, canonical JSON (sorted keys, compact, UTF-8, RFC3339 Z) with
  golden-bytes tests pinning serialization.
- `validate.py` is pure: returns Findings, never raises, never does I/O.
- ONE redacting writer is the only path to disk under runs/; redact → hash →
  temp+fsync+rename; placeholders carry NO secret fingerprint; writer FAILS LOUD.
- Subprocess: argv list, `shell=False`, explicit env built from `{}` (never
  filtered `os.environ`), `stdin=DEVNULL`, `cwd=snapshot realpath`,
  `start_new_session=True`, process-group SIGTERM→SIGKILL on timeout, stdout
  AND stderr byte caps with concurrent drains, ANSI strip, pinned executable
  path + sha256 check before spawn.
- Missing/failed worker = recorded absence; NEVER substitution.
- Hermetic tests: autouse guards on `shutil.which`, ALL subprocess entry points,
  and sockets; `real_subprocess` marker for the few group-kill/cap tests that
  must spawn `sys.executable`.
- Corpus snapshots must be history-truncated; a `snapshot.py` builder + a
  `test_snapshot_has_no_future` test are IN scope (two planners flagged the
  omission).
- Idempotency key for worker calls EXCLUDES `arm` (that is what makes the paired
  ablation share proposals across arms 3/3b/4) and INCLUDES `repeat_index`.
- Every retry attempt is an event; failed attempts' cost counts.
- Budget-tripped cells are MISSING, not ABSTAIN.
- `dissent`/`residual_risks`: required keys, empty lists allowed; validator
  emits an error only when contest exists (or on ACCEPT with empty residual
  risks) — NOT schema-invalid when empty (honest ABSTAIN must be expressible).
- "ref predates claim revision" applies ONLY to `phase=verification` evidence;
  evidence-pack items legitimately predate every proposal.
- Security-critical code (launcher, redactor, writer, allowlist, snapshot)
  lives in `src/eris/` under mypy strict; `eval/run.py`/`score.py` are thin CLIs.

## D. Selected design (what to build) — MILESTONE 1 (this cycle)
Python ≥3.12, src layout `src/eris/`:
- `version.py`, `schemas.py` (records per architecture table, enums, Location,
  canonical_bytes), `validate.py` (codes: REF_MISSING, REF_MODEL_ASSERTED,
  REF_PREDATES_CLAIM[verification phase only], SUPPORTED_WITHOUT_REFS,
  DISSENT_EMPTY_WITH_CONTEST, RESIDUAL_RISKS_EMPTY_ON_ACCEPT, ORIGIN_MISMATCH,
  UNVERIFIED_CHALLENGE[warning], SEQ_GAP, HASH_MISMATCH, SCHEMA_VERSION;
  `enforce_rulings` downgrades + escalates at ≥3).
- `policy.py`: Pydantic policy model (`extra="forbid"`, fail-closed required
  fields: executable_sha256, timeout_s, max_stdout_bytes, vendors_allowed;
  trusted default false; secret-shaped value → refuse load; api base_url host
  allowlist; policy sha256 computed). `policies/default.yaml` example with
  placeholder hashes and a documented `eris policy pin` step (computes sha256 of
  declared executables and writes them — trivial helper).
- `redact.py`: Redactor (pattern set per security §2.2 + exact values; ANSI/C1
  strip first; folded-whitespace view; base64 runs ≥32 decoded and rematched;
  placeholder `[REDACTED:<pattern_id>#<ordinal>]`; returns counts).
- `writer.py`: RunWriter (put_blob, append(Event with seq, ts, prev_sha,
  payload_sha256), finalize(manifest last), flock single-writer, torn-tail
  detection on open-for-resume, raises on failure).
- `launch.py`: argv builders per CLI (claude: `-p <prompt> --safe-mode
  --permission-mode plan --tools <list or ""> --no-session-persistence
  --output-format json [--json-schema] --max-budget-usd N`; codex: `exec -C
  <cwd> -s read-only --ephemeral --ignore-user-config --ignore-rules
  -c project_doc_max_bytes=0 --skip-git-repo-check -m <model> --json
  [--output-schema F] [-o F] <prompt>`; gemini: `-p <prompt> -m <model>
  --approval-mode plan -o json`; grok: `-p <prompt> -m <model>
  --permission-mode plan --disable-web-search --output-format json
  [--json-schema]`), FORBIDDEN-flag assertions (`--bare`, `bypassPermissions`,
  `workspace-write`, `yolo`), env builder (base + per-CLI + NEVER list),
  `spawn()` via injectable Popen with caps/kill/reap, envelope parsers (claude
  [fixture 2.1.239 captured today], codex JSONL, grok JSON [captured today],
  gemini defensive), `WorkerResult`.
- `verify.py`: allowlist grammar (argv[0] pinned realpath+hash; literal flags;
  flag=value regexes; positional paths realpath under snapshot; pytest/git/ruff/
  mypy deny lists per security §4; git env: GIT_CONFIG_GLOBAL=/dev/null,
  GIT_CONFIG_NOSYSTEM=1, GIT_PAGER=cat, GIT_TERMINAL_PROMPT=0; NEVER list incl.
  PYTEST_ADDOPTS/PYTEST_PLUGINS/PYTHONPATH/GIT_*/DYLD_*/LD_*/SSH_AUTH_SOCK/AWS_*).
- `snapshot.py`: mirror → branch at pre-fix sha → `git clone --no-local --depth N
  --single-branch --branch` → remove origin/FETCH_HEAD/ORIG_HEAD; verifier
  function implementing `test_snapshot_has_no_future` checks.
- `doctor.py`: filesystem/config-only preflight; never prints secret VALUES;
  flock probe; `--probe` runs `<cli> --version`.
- `eval/run.py` thin CLI: `preflight`, `--dry-run` (prints argv/env NAMES/cwd/
  idempotency keys; zero subprocess), and a single-worker `invoke` path wired
  end-to-end (propose stage only). Arms/critique/adjudicate orchestration and
  `score.py` are MILESTONE 2.
- Tooling: pyproject (ruff E4,E7,E9,F,B,I + format; mypy strict src;
  pydantic.mypy plugin; coverage source src+eval fail_under 80), requirements.txt
  exact pins (pydantic 2.13.4, pyyaml 6.0.3, httpx 0.28.1, ruff 0.16.4, mypy
  2.3.1, pytest 9.1.1, pytest-cov 7.1.0, pre-commit 4.6.2, pip-audit 2.10.1,
  types-PyYAML) — verify each installs on 3.14; Taskfile; CI (3.12/3.14,
  pip-audit blocking); pre-commit; .gitignore (+runs/, cache/, snapshots).
- Tests per testing critic §1 + security tests §1–5 + reliability tests R1–R6
  for the modules above; fixtures under tests/fixtures/envelopes/<cli>/<ver>/
  with .meta.json sidecars (claude 2.1.239 and grok 1.0.5 and codex 0.147.0
  envelopes captured today are provided in scratchpad/flagtest/out/ — REDACT
  before committing: strip session ids/thread ids are fine to keep; no secrets
  present but scan anyway).
- Docs: README, AGENTS.md (canonical), CLAUDE.md pointer, docs/{PROTOCOL,
  ARCHITECTURE,SECURITY,INVARIANTS,EVAL-PLAN}.md (INVARIANTS lists each
  enforced rule with its test name), docs/history/DESIGN-2026-08-21.md.

## E. Rejected alternatives (and why)
- Orchestrator/state machine/ledger package now — rejected (engine before evidence).
- `--bare` — breaks OAuth [EXP]. `openai` SDK — unnecessary. SQLite now —
  unnecessary. LangGraph — checkpoints ≠ decision record. Dropping unevidenced
  challenges — suppresses valid uncertainty. Non-empty-dissent schema rule —
  forces fabrication. Filtering os.environ — leaks. Hash-fingerprint
  placeholders — secret leak. pip-audit non-blocking — documented triage rule instead.
