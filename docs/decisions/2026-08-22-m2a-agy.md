# Engineering decision record — Milestone 2a: Antigravity (`agy`) worker + experiment results

Date: 2026-08-22 · Branch: `m2a-agy` → `main` · Synthesizer: Claude (Fable 5) · Implementer: Claude, one isolated worktree · Advisor: Codex (OpenAI, cross-family, block authority), run via `codex exec -s read-only` directly because the plugin's job store dropped two earlier long-running reviews.

## Selected approach
- Replace the uninstalled Gemini CLI worker with Google's Antigravity CLI
  `agy` 1.1.18. Canonical argv: `agy -p <prompt> --model <gemini-*>
  --mode plan --sandbox --add-dir <snapshot realpath> --output-format json
  --disable-slash-commands --print-timeout <N>s [--json-schema <inline>]`,
  with `--add-dir` asserted to equal the spawn cwd exactly once.
- Parser: `status != SUCCESS` → failure; `structured_output` preferred;
  usage mapped; no model id / cost (envelope has none); `conversation_id`
  and `duration_seconds` recorded on the Invocation → `SCHEMA_VERSION 0.1.2`
  (new goldens dir + MANIFEST block; 0.1.0/0.1.1 byte-identical, pinned).
- Policy: `CliName` claude|codex|agy|grok; syntactic lineage guard (agy model
  must start with `gemini-`); NEVER-env additions for Google/Antigravity
  credential and endpoint overrides; `AGY_CLI_DISABLE_AUTO_UPDATE=1`
  (ASSUMPTION — name from binary strings).
- `parse_grok` reads `structuredOutput`; Gemini builder/parser removed with a
  source-level guard; fixtures for every live capture, home path redacted.
- `eris.version` 0.1.1 → 0.2.0.

## Dissent and corrections (preserved)
- **Implementer vs synthesizer:** the implementer found `--disable-slash-commands`
  prints "`--mode plan` has no effect while slash command expansion is
  disabled" — the protection is agy's non-interactive permission check, not
  plan mode. Accepted; documented as the actual mechanism.
- **Synthesizer's own scope was wrong twice:** (1) `--add-dir` was listed as
  FORBIDDEN; live tests (A14/A15/A16) showed agy cannot read *inside* the cwd
  without a declared workspace and confines reads to it once declared → now
  REQUIRED. (2) the "E1 pass" from A10b was vacuous (no workspace); the valid
  pass is A16.
- **Security critic's claim that `grok --sandbox strict` confines reads**
  (from Grok's bundled docs) was REFUTED live (E1b leaked the canary).
- **Testing + architecture critics vs scope:** `structured_output` in the A3
  capture is exactly the schema object; the extra keys were in the prose.
  Scope corrected.
- **Codex round 1 (8 must-fix):** parser `OverflowError` escape; `timeout_s`
  not strict/bounded and print-timeout formula wrong for small timeouts;
  argv-order inconsistency between prompt and plan (resolved: code order is
  canonical); 0.1.2 block not independently pinned; fixture provenance
  overstated; username guard not portable; three stale doc lines; decision
  record absent. All accepted.
- **Open (user decision, unchanged from M1):** E1 containment. All of claude
  (`--safe-mode --permission-mode plan --tools Read,Grep,Glob`), codex
  (`-s read-only`), grok (plan; also `--sandbox strict`) READ files outside
  the snapshot. Only agy confines reads (in-process policy, with a declared
  workspace). Options and recommendation (dedicated low-privilege macOS user)
  are in `docs/SECURITY.md`. Until chosen: plumbing and clean-control runs
  only; no defect-detection or ABSTAIN scoring.
- **Residuals recorded:** agy injects the workspace's AGENTS.md/GEMINI.md
  (A15 "MANGO KIWI"), no opt-out → per-worker snapshot sanitization is M2b;
  agy persists full transcripts + SQLite under `~/.gemini/antigravity-cli/`
  (~1 MB/run; doctor WARNs on size; Eris never deletes vendor state); agy
  spawns a background auto-updater that would change the binary under its
  pin; the executed model is unobservable (A9 log: "not in local config,
  defaulting"); `--tools ""` on claude HANGS on tool-requiring prompts (E8) —
  adjudicator prompts must be pure text.
